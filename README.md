# Lingua Arena

일상에서 쓰는 외국어를 8개 언어로 비교하며 배우는 무료 학습 사이트 (영어·프랑스어·독일어·스페인어·포르투갈어·한국어·일본어·중국어).
A1~C2 단계마다 어휘·문법·듣기·읽기·말하기·쓰기 6영역. 바닐라 HTML/CSS/JS, 빌드 없음.

- 설계: [`docs/blueprint.md`](docs/blueprint.md)
- 데이터 검증: `python3 tools/validate.py`
- 로컬 실행: `python3 -m http.server` 후 `http://localhost:8000`
- 기존(이전 버전) 사이트: `_legacy/` (배포되지 않음)

시험 이름(TOEIC, TOEFL, IELTS 등)은 각 소유자의 상표이며 이 프로젝트는 해당 기관과 무관합니다. 문제는 모두 형식만 참고해 새로 만든 오리지널입니다.
